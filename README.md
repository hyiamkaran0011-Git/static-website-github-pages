# Task 6: Host a Static Website with GitHub Pages

## Objective
Deploy a simple HTML website using GitHub Pages.

## What I did
1. Created `index.html` and `style.css`
2. Pushed them to this GitHub repository
3. Enabled GitHub Pages (Settings → Pages → main branch, root folder)
4. Customized the page with CSS
